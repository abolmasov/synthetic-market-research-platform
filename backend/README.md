# Backend (NestJS API)

NestJS 11 API for the Synthetic Market Research Platform.

## Local Run

```bash
cp .env.example .env
npm install
npm run start:dev
```

Default API URL: `http://localhost:3003`

Swagger UI: `http://localhost:3003/api`

## Tests

```bash
npm test
```
